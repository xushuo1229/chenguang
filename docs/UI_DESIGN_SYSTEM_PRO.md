# 知行 ·UI设计系统PRO「Calm Dawn Pro」

> Phase UI-PRO 视觉升级版
> 适用页面：`login.html` / `index.html` / `workbench.html` / `stats.html` / `goals.html` / `ai.html`
> 实现层：新增 `assets/calm-dawn-pro.css`，经页面样式后置加载；不修改后端、数据模型、`store.js`、`sync.js` 或业务 JS。

# 1. 当前 UI 审计

| 页面 | 当前问题 | 升级目标 |
|---|---|---|
| Login | 左右分区信息完整，但卡片边界感偏重，移动端留白不足 | 更安静、更聚焦，弱化边框，强化品牌与输入层级 |
| Home / Landing | 功能介绍清晰，但模块密度较高，视觉节奏缺少呼吸 | 放宽区块间距，用轻卡片与更清晰的层级引导 |
| Workbench | 信息完成度高，但功能卡密集，首屏容易变成后台面板 | 把“下一步行动”作为视觉主轴，功能卡保持一致节奏 |
| Stats | 图表数据丰富，但分区块边缘感强，移动端密度高 | 用更轻的分隔和统一数据卡层级，移动端优先降密度 |
| Goals | 结构清楚，但目标状态色彩略显系统化 | 用阶段化卡片和更柔和的状态反馈表达长期目标感 |
| AI | 已有数据面板，但聊天区与分析区略偏工具感 | 强化“成长教练陪伴”，让数据摘要与对话更连贯 |

# 2. 设计原则

1. **少即是清楚**：一个视口只有一个主行动，减少边框和阴影竞争。
2. **结构即信息**：数据卡片、标签、进度和状态用统一层级表达。
3. **成长有温度**：AI 不做科技感机器，而做安静、可信的长期陪伴者。
4. **留白即高级**：放大区块间距、标题呼吸和卡片内边距。
5. **移动优先**：先保证单手可读、可点，再做桌面多栏布局。
6. **微动效**：只使用淡入、轻微上浮、焦点反馈，不做循环炫技动画。

# 4. 六页视觉方案

## 登录

* *关键词**：安静入口 · 品牌晨光 · 清晰表单

原型：

1. 左侧品牌区保留晨光表达，但降低装饰密度。
2. 右侧表单区使用大留白和低边界感输入框。
3. 登录主按钮保持琥珀实底，输入框只做焦点环反馈。
4. 移动端品牌区收窄，表单优先。

## 主页 / 着陆

* *关键词**：价值第一屏 · 结构化功能 · 轻量引导

原型：

1. Hero 标题加大字距对比，副文案保持一段可读宽度。
2. 功能卡由密集网格改为更安静的 2–3 栏结构。
3. 数据说明区以文字为主，插画作为辅助，不再抢层级。
4. CTA 区保留单一主按钮，避免多主色抢焦点。

## 工作台

* *关键词**：今天做什么 · 行动主轴 · 记录分区

原型：

1. 今日计划作为首屏主卡，视觉权重最高。
2. 「下一步行动」使用琥珀弱底提示，不使用强渐变。
3. 课程、阅读、英语、专注、运动保持同节奏卡片。
4. 移动端先展示今日行动，再展开记录模块。

## 统计

* *关键词**：成长证据 · 可读趋势 · 低噪音图表

原型：

1. 顶部时间范围做成分段控件，主选中项用琥珀。
2. 概览、趋势、热力图统一卡片内边距与标题层级。
3. 图表区域不做额外装饰，让数据本身成为视觉主体。
4. 空状态给出明确“去完成第一个记录”的行动入口。

## 目标

* *关键词**：长期方向 · 阶段感 · 轻目标卡

原型：

1. 目标卡使用统一标题、进度、阶段和剩余时间层级。
2. 状态色降低饱和度，只保留语义表达。
3. 进度条高度保持 6px 左右，避免用力过猛。
4. 空状态引导创建第一个目标，成功创建后引导回工作台记录。

## AI

* *关键词**：成长教练 · 数据画像 · 陪伴感

原型：

1. 左侧数据面板作为教练观察证据，右侧对话作为教练回应。
2. AI 图标、消息与建议使用低饱和紫，不做科技蓝。
3. 对话气泡使用柔和圆角和低阴影。
4. 移动端先展示今日状态，再展示发现、风险与建议。

# 5. 微动效规范

| 场景 | 效果 |
|---|---|
| 页面进入 | 主内容淡入 + 轻微上移，360ms 一次 |
| Card hover | Border highlight   Move up 1–2px   Shadow deepen |
| Button click | Slight scale(0.98) |
| Input focus | 2px amber focus ring |
| Popup | Fade   Scale(0.98 → 1) |

所有动画遵守 `prefers-reduced-motion`。

# 6. 禁止事项

1. 不做大面积渐变、荧光、发光、霓虹和粒子。
2. 不使用虚假数据填充视觉。
3. 不为视觉新增业务 JS。
4. 不引入 React / Vue / Tailwind。
5. 不修改数据库模型、同步协议、认证逻辑。
6. 不删除既有功能或改变页面语义。
