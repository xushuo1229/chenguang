# 第23.2.1阶段 最终报告

日期：2026-09-17
状态：就绪

# 1. 实施摘要

Added AI Daily Reflection backend capability. This capability only consumes GrowthContext and converges AI output into structured review results.

- Added a dedicated Reflection Prompt Builder.
- Added `dailyReflection()` service method.
- Added `POST /api/ai/reflection`.
- `performance` is deterministically generated by the backend from GrowthContext, AI cannot forge behavior numbers.
- Empty GrowthContext, Provider failure, and invalid JSON are all handled securely.

Reflection 不是聊天系统、不是新数据系统、不是自动执行代理。

# 2. 数据流

```text
GrowthContext
      ↓
Reflection Prompt
      ↓
AI Service
      ↓
Reflection API
```

服务内部流程：

```text
GrowthContext / AIContext.growthContext
      ↓
normalizeGrowthContext()
      ↓
promptBuilder.buildReflectionPrompt()
      ↓
Provider Adapter
      ↓
parseReflectionJson()
      ↓
后端生成 performance
      ↓
structured reflection
```

# 4. API 合同

## 请求

```http
POST /api/ai/reflection
Authorization: Bearer <JWT>
X-Requested-With: XMLHttpRequest
Content-Type: application/json
```

```json
{
  "context": {
    "version": "1.0",
    "today": "2026-09-17",
    "taskSummary": {},
    "focusSummary": {},
    "streaks": {},
    "goals": {},
    "signals": {}
  }
}
```

`context` supports directly passing in GrowthContext, and also supports passing in AIContext that contains the `growthContext` field. The backend only extracts GrowthContext and does not consume the full history or the complete conversation session.

## 成功响应

```json
{
  "data": {
    "reflection": {
      "summary": {
        "title": "",
        "overview": ""
      },
      "performance": {
        "tasks": {},
        "focus": {},
        "learning": {}
      },
      "insights": [],
      "suggestions": []
    }
  },
  "meta": {
    "contextVersion": "1.0",
    "model": "provider-model"
  }
}
```

## 错误响应

继续使用项目统一错误结构：

```json
{
  "error": {
    "code": "AI_INVALID_RESPONSE",
    "message": "AI 复盘暂时不可用，请稍后再试"
  }
}
```

# 5. 响应模式

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `summary.title` | 人工智能 | 今日简短标题 |
| `summary.overview` | 人工智能 | 今日总体说明 |
| `performance.tasks` | 成长背景 | 任务总数、完成数、待完成、完成率、昨日遗留 |
| `performance.focus` | 成长背景 | 专注分钟数与今日是否活跃 |
| `performance.learning` | 成长背景 | 学习与运动分钟数 |
| `insights[]` | 人工智能 | 基于数据的趋势或观察 |
| `suggestions[]` | 人工智能 | 可执行建议 |

`performance` 一律由后端覆盖生成；模型返回的 performance 会被丢弃。
